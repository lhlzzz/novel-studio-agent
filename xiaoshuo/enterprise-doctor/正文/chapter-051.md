# 第51章 名片夹层里的求救信号

林川把自己的账算到凌晨两点。

最后一笔写完，他盯着那张A4纸看了很久。纸上的数字很诚实：如果他再这样干三个月，就得回老家找份正经工作。不是他不想坚持，是账本不允许他用情怀当饭吃。

他把纸折起来，塞进旧账本最后一页。

就在合上账本的时候，夹层里滑出一张名片。

名片很旧，边角已经磨毛了。上面印着：王富贵，富贵机加工厂，联系电话139XXXX。背面用圆珠笔写了一行字：林医生，我这厂子快撑不住了，能帮我看看吗？

林川愣了一下。

这张名片是上个月一个客户塞给他的。当时那个客户说，他有个远房亲戚开小厂，工人发不出工资，想找林川看看。林川当时正忙着帮米粉阿姨梳流水，就把名片随手夹进账本，后来就忘了。

现在这张名片掉出来，像是在提醒他：你自己的账还没算明白，就又有人找你救命了。

林川把名片翻来覆去看了几遍。

最后他拿起手机，拨了那个号码。

响了七声，对面才接起来。声音很疲惫："喂？"

"王老板？我是林川，企业急诊医生。"林川说，"你之前托人给我留了张名片。"

对面沉默了两秒，然后声音突然提高："林医生？！你真的打过来了？"

"嗯。"林川说，"你那边现在方便说话吗？"

"方便方便！"王富贵的声音里带着一种快要溺水的人抓到救生圈的急切，"林医生，我这厂子真的快撑不住了。三十个工人，这个月底工资发不出来。我不是不想发，是真的没钱了。"

林川听出来了，这不是装的。

"你先别急。"林川说，"我问你几个问题。第一，你欠工人多少钱？"

"二十三万。"王富贵说，"这是上个月和这个月的工资。"

"第二，你厂子现在还在接单吗？"

"接。"王富贵说，"但是接了也不敢做。因为做完了，客户拖款。我现在手里压着四十多万的应收账款，都是客户欠我的。可我催不回来，工人工资就发不出去。"

林川在纸上记下这两个数字：欠工人23万，客户欠40万。

"第三，你的工人知道发不出工资吗？"

"知道。"王富贵声音更低了，"我上周已经跟他们说了。有几个老员工说可以再等等，但是有十几个人已经在找下家了。林医生，我不怕厂子倒，我怕的是工人走了以后，我连翻身的机会都没了。"

林川听到这里，心里有了底。

这可不是一个简单的资金链断裂问题。这是一个"应收账款-工资支付-员工流失"的三角死锁。客户不给钱，工人发不了工资；工人要走，订单做不了；订单做不了，客户更不会给钱。

这种死锁，林川见过。

但这次不一样。

就因为这次他自己也在算账。他刚刚才写完"白救不是仁义，白救是慢性自杀"。如果他现在接了这个案子，又是一次义诊，那他自己的账本就真的要见底了。

可如果他不接，三十个工人就要散。

林川沉默了几秒。

"王老板，我明天过去看看。"他最后说，"但我得先跟你说清楚，我这次不能白干。"

对面愣了一下："林医生，你要收费？"

"对。"林川说，"我会先给你做诊断，诊断完了报价。如果你觉得价格合理，我们再谈怎么干。如果你觉得贵，你可以不接受。"

王富贵沉默了更久。

"林医生，不是我不想给钱。"他最后说，"是我现在真的拿不出来。"

"我知道。"林川说，"所以我会根据你的实际情况报价。但有一点你得明白——我不是慈善机构，我也得活。"

这句话说出来，林川自己都觉得有点硬。

但他必须说。

因为他刚刚才在自己的账本上写下"医生第一条戒律：先确保自己活着，才能继续救人"。

王富贵又沉默了几秒。

"行。"他最后说，"林医生，你明天过来吧。我厂子在远郊，坐地铁转公交要两个小时。我把地址发给你。"

"好。"林川说，"明天见。"

挂掉电话，林川看了看时间。凌晨两点半。

他没有马上睡。而是又翻开账本，在"林川企业急诊服务·标准化条款（第一版）"下面，写了第二行：

"第二行：诊断收费，处方收费，执行收费。分开报价，分开决策。"

写完这一行，他又加了一句：

"客户可以只买诊断，不买处方；可以只买处方，不买执行。但每一步都得明码标价，不许含糊。"

这是他第一次给自己定规矩。

以前他总觉得，谈钱伤感情。可今天他才明白，不谈钱才是真的伤。因为不谈钱，最后伤的是自己。

第二天早上八点，林川坐上了去远郊的地铁。

地铁转公交，公交转小巴，小巴下来还要走二十分钟。等他到富贵机加工厂门口的时候，已经快十一点了。

厂子不大，就是一个两层的铁皮厂房，外面堆着一些生锈的钢材和半成品零件。门口挂着一块褪色的牌子：富贵机加工厂。

王富贵在门口等他。

人很瘦，四十多岁，头发有点白，眼睛里全是血丝。看见林川，他赶紧迎上来："林医生，你来了。"

"嗯。"林川点头，"带我看看厂子。"

王富贵带他进了厂房。

厂房里有十几台机床，大部分都在运转。工人们穿着油腻的工作服，戴着护目镜，在机床前忙碌。空气里弥漫着机油和金属切削的味道。

林川扫了一眼，心里有了第一个判断：这厂子还在干活，说明还没到最后关头。

"你们现在在做什么订单？"林川问。

"汽配厂的零件。"王富贵说，"这批订单是上个月接的，做完了能收十二万。但是客户说要等他们收到下游的款才能给我。"

"下游是谁？"

"一家汽车厂。"王富贵说，"但是那个汽车厂最近也在压款。所以我这边就一直收不到钱。"

林川在心里记下这条链：汽车厂压款→汽配厂收不到钱→汽配厂压王富贵的款→王富贵发不出工资。

这是一条典型的"应收账款传导链"。上游一压，下游全死。

"你有没有跟汽配厂签合同？"林川问。

"签了。"王富贵说，"合同上写的是货到付款。"

"那你货交了吗？"

"交了。"王富贵说，"上周就交了。但是他们说财务流程要走一个月。"

林川听到这里，眉头皱了一下。

"货到付款，不是货到就付吗？"他问。

王富贵苦笑："合同是这么写的。但是实际操作，他们都说要走流程。我也没办法，我不敢得罪他们。因为我这厂子，百分之六十的订单都是他们给的。"

林川明白了。

这不是简单的拖款问题。这是一个"客户绑架"问题。王富贵的厂子太依赖这一个大客户，所以客户可以随意压款，他不敢反抗。

"你有没有想过分散客户？"林川问。

"想过。"王富贵说，"但是其他客户的订单量小，价格也低。我算过，如果我不接汽配厂的单子，光靠其他小客户，连工人工资都发不出来。"

林川点点头。

这是一个典型的"大客户依赖症"。短期看，大客户给的订单多，利润高；长期看，大客户一旦压款或者撤单，小厂就直接死。

他在心里记下第二个诊断点：客户结构失衡。

"带我看看你的账。"林川说。

王富贵带他进了办公室。

办公室很简陋，就一张桌子，一台老旧的电脑，墙上贴着一张手写的生产排期表。

王富贵从抽屉里拿出一个文件夹，里面是一堆发票、合同和手写的账本。

林川接过来，一页一页翻。

翻了十分钟，他看出了问题。

王富贵的账本上，有四种账：

第一种是"客户应收账款"，总共四十三万，分散在七个客户手里。其中汽配厂一家就占了二十八万。

第二种是"供应商应付账款"，总共十五万，是欠原材料供应商的钱。

第三种是"工人工资"，欠了两个月，总共二十三万。

第四种是"银行贷款"，还有八万没还，每个月要还利息三千多。

林川把这四笔账列在纸上，然后问王富贵："你现在账上还有多少现金？"

"两万。"王富贵说，"这是我留着应急的。"

林川点点头，然后在纸上写下一个公式：

现金2万 + 应收43万 - 应付15万 - 工资23万 - 贷款8万 = -1万

"你现在的净资产是负一万。"林川说，"但这还不是最大的问题。"

王富贵愣了一下："那最大的问题是什么？"

"最大的问题是，你的应收账款里，有二十八万压在一个客户手里。"林川说，"如果这个客户不给钱，或者拖三个月，你的厂子就会进入'工人流失-订单停滞-客户撤单'的死亡螺旋。"

王富贵脸色白了。

"那我该怎么办？"他问。

林川没有马上回答。

他看着王富贵，想起了昨晚自己写的那句话："先诊断，后报价。"

"王老板，我现在给你做完了初步诊断。"林川说，"你的问题不是简单的缺钱，而是'客户结构失衡+应收账款传导链+工资支付死锁'三个问题叠加。如果你想解决，我可以给你写一份处方。但是在写处方之前，我得先跟你谈谈价格。"

王富贵看着他，眼神里有点慌。

"林医生，你要多少钱？"

林川深吸一口气。

"诊断费，五千。"他说，"这是我今天过来看你厂子、翻你账本、给你找出问题的费用。这笔钱，不管你接不接受我的处方，都得付。"

王富贵愣住了。

"五千？"他声音有点抖，"林医生，我现在账上只有两万，这两万还得应急。你一下子要走五千，我……"

"我知道你难。"林川打断他，"但是王老板，你得明白一件事——我今天早上八点出门，坐了三个小时车过来，看了你的厂子，翻了你的账，给你找出了三个致命问题。这些工作，不是免费的。"

王富贵张了张嘴，没说出话。

林川接着说："如果你觉得五千块贵，你可以不付。但是你得自己想清楚——你现在欠工人二十三万，欠供应商十五万，客户欠你四十三万。你不解决这三个问题，你的厂子撑不过这个月。五千块的诊断费，能帮你看清楚问题在哪儿，值不值？"

王富贵沉默了很久。

最后他点了点头。

"值。"他说，"林医生，我付。"

林川松了一口气。

这是他第一次真正收费。

虽然只是五千块，但这五千块，是他给自己定的第一条生存线。
