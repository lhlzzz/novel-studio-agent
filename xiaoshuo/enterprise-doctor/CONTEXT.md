# 《我在破产边缘给老板们当急诊医生》共同语言 / CONTEXT

生成时间：2026-05-09
用途：统一小说项目领域语言，避免主书设定漂移。

## 1. 一句话定位

《我在破产边缘给老板们当急诊医生》是都市经营轻爽文，不是玄幻、万界、快穿、系统流、游戏副本流。

核心读感：现实小店快倒闭，林川像急诊医生一样找病灶、止血、抢救、复盘，让老板活下来，也让自己从破产边缘爬回来。

## 2. 固定术语

### 急诊医生

含义：经营急诊医生。

林川抢救的是：
- 现金流
- 客流
- 履约
- 动线
- 口碑
- 合同
- 平台规则
- 老板误判
- 顾客真实痛点

不是医学神医，不靠针灸/药方/玄学治病。

### 病灶

含义：小店经营失败的真正原因。

常见病灶：
- 卖得越多亏得越多
- 低价活动烧死现金流
- 老板只看热闹不看账
- 动线堵死早高峰
- 平台推荐带来履约压力
- 情怀压过标准化
- 人情账拖垮经营账

### 急诊账本 / 旧账本

含义：林川的复盘工具、观察工具、记账工具。

允许：
- 记录病灶
- 记录风险
- 记录复盘结论
- 作为林川思考载体

禁止：
- 变成系统面板
- 派发任务奖励
- 自动给答案
- 直接送钱
- 变成万界入口

### 食物微特性

含义：现实轻奇迹，必须克制。

允许：
- 爆柠茶让烦躁的人缓一口气
- 热包子让早起的人胃里有底
- 热豆浆让疲惫打工人恢复一点状态

禁止：
- 治病神物
- 灵丹妙药
- 修仙功效
- 属性加点
- 夸张战力提升

### 副本感

含义：经营压力的结构感、危机感、阶段挑战感。

允许：
- 早高峰像战场
- 写字楼午餐像迷宫
- 夜市雨夜像生存局
- 平台推荐像压力锅

禁止：
- 真副本
- 穿越世界
- 万界订单
- 游戏世界
- 系统任务
- 头顶数值

### 老板急诊

含义：每个单元案都要救一个老板/小店/经营节点。

标准闭环：
入口 → 病灶 → 误诊 → 抢救 → 反噬 → 结算 → 下一案钩子。

## 3. 主角林川

关键词：欠债、年轻、嘴贫但不油、会观察、会算账、能扛事、有底层共情但不圣母。

林川的爽点来自：
- 看见别人看不见的经营病灶
- 用低成本动作止血
- 敢说真话但不装大师
- 能把复杂经营问题变成老板听得懂的动作
- 每救活一家店，也推进自己的还债、名声、人脉和能力

禁止写法：
- 商业导师附体
- 霸总式装逼
- 纯靠金手指
- 无代价胜利
- 只讲道理不行动

## 4. 每章验收语言

每章写完必须能回答：

1. 本章救的是什么病？
2. 本章林川做了什么具体动作？
3. 本章爽点是什么？
4. 本章代价或反噬是什么？
5. 本章章末下一问是什么？
6. 本章有没有污染主书定位？

## 5. 禁令

主书禁止硬塞：
- 万界送外卖
- 快穿
- 真副本
- 游戏世界返还
- 系统面板
- 属性点
- 修仙能力
- 医学神医路线
- 纯商业课说教

这些如果要写，另开新书，不混主书。
