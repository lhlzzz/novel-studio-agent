- 个体户与本地服务老板、前台、1–10 人小团队

## 3. Voice

- 口语、短句、场景化  
- 形容词：清楚、具体、克制、有人味  
- 避免：播音腔、保证收益、密密麻麻字幕墙

## 4. Content pillars

1. **重复劳动**（回复/报价踩坑）  
2. **三步结构**（草稿表 / 整理表 / 日历）  
3. **平台适配**（同一核多平台）  
4. **边界与合规**（什么不做）  
5. **复盘**（drop reason / 停留，内部）
