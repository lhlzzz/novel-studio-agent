# Story Writing Skills for MeitiAgent

## Purpose
Net novel writing and analysis tools for content generation.

## Core Skills
- story-long-analyze: Long-form novel dissection
- story-short-analyze: Short-form novel dissection
- story-long-write: Long novel writing
- story-short-write: Short novel writing
- story-cover: Novel cover generation
- story-deslop: Remove AI writing traces
- story-import: Import existing novels

## Usage
Load story skills when content requires novel-style narrative.

## Example Load
```markdown
Skills: story.story-long-analyze, story.story-cover, story.story-deslop
```
